# Лабораторная работа №4 — Основы JavaScript

## Описание
Добавление интерактивности на страницу с помощью JavaScript. Реализован скрипт анализа времени автономной работы гаджетов с использованием функций, циклов, условных конструкций и базовых методов ввода-вывода.

**Вариант:** 12  
**Тема:** Техногик и обзорщик гаджетов (время автономной работы)  
**Инструменты:** JavaScript, консоль браузера, редактор кода

## Цель работы
Познакомиться с синтаксисом JavaScript, базовыми конструкциями и логикой программирования. Научиться инкапсулировать логику в функции и отлаживать код с помощью инструментов разработчика.

---

## Требования и реализация

### 1. Ввод и вывод данных
| Метод | Где использован | Назначение |
|-------|----------------|-----------|
| `prompt()` | Функция `greetUser()` | Запрос имени пользователя |
| `alert()` | Функции `greetUser()`, `showFinalResult()` | Приветствие и итоговый результат |
| `console.log()` | Весь скрипт | Вывод технической информации и результатов анализа |

### 2. Условные конструкции и циклы
- **`if...else`** — проверка энергоэффективности (`checkEnergyEfficiency`)
- **`for`** — проход по массиву в функциях `findMax`, `filterAbove`, `calculateSum`, `countLowBattery`

### 3. Функции (инкапсуляция логики)
Вся логика инкапсулирована в функции согласно принципу единственной ответственности:

| Функция | Назначение |
|---------|-----------|
| `greetUser()` | Приветствие пользователя через `prompt` и `alert` |
| `getBatteryData()` | Возврат массива данных (время работы в часах) |
| `findMax(arr)` | Поиск максимального значения в массиве |
| `filterAbove(arr, threshold)` | Фильтрация массива (элементы > порога) |
| `calculateSum(arr)` | Подсчёт суммы элементов массива |
| `calculateAverage(arr)` | Вычисление среднего значения |
| `countLowBattery(arr, threshold)` | Подсчёт устройств с малым временем работы |
| `calculateShare(count, total)` | Вычисление доли в процентах |
| `checkEnergyEfficiency(average)` | Проверка среднего времени (< 6 часов) |
| `showFinalResult(average, count)` | Вывод итогового результата через `alert` |
| `analyzeGadgets()` | Главная функция — оркестрация всего анализа |

### 4. Логика анализа
**Исходные данные:** массив из 7 чисел — время автономной работы гаджетов в часах:  
`[12, 3, 18, 5, 24, 2, 10]`

**Реализованная логика:**
- **Фильтрация:** гаджеты с временем работы > 8 часов (долгожители)
- **Цикл:** подсчёт устройств с малым временем (≤ 4 часов) и их доли
- **Функции:** поиск максимума, фильтрация, подсчёт суммы и среднего
- **Дополнительное условие:** если среднее < 6 часов — предупреждение об энергоэффективности

### 5. Результаты анализа
| Показатель | Значение |
|------------|----------|
| Максимальное время работы | 24 часа |
| Устройства-долгожители (> 8 часов) | 4 устройства |
| Среднее время работы | 10.57 часов |
| Устройства с малым временем (≤ 4 часов) | 2 устройства (28.6%) |
| Энергоэффективность | Приемлемая (среднее ≥ 6 часов) |

## Процесс отладки

### Используемые инструменты
1. **`console.log()`** — вывод промежуточных значений переменных и состояния программы
2. **Консоль браузера (DevTools, F12)** — просмотр всех выводов, ошибок и предупреждений
3. **Breakpoints (вкладка Sources)** — остановка выполнения на конкретной строке для пошаговой отладки
4. **Панель Scope** — просмотр значений переменных в текущей области видимости
