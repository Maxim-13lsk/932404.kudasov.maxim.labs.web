# Лабораторная работа №3 — Вёрстка макета с помощью Flexbox и Grid

## Описание
Дополнение и улучшение макета страницы из ЛР №2. Реализованы одномерные макеты с помощью **Flexbox**, двумерные макеты с помощью **CSS Grid**, продвинутая адаптивная вёрстка, семантические теги и машинно-читаемые данные через тег `<data>`.

**Вариант:** 12  
**Тема:** Техногик и обзорщик гаджетов  
**Стиль:** Металлик, серебристо-чёрная цветовая гамма

## Цель работы
Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки, семантической разметки и обеспечения доступности (контрастности).

---

## Требования и реализация

### 1. Flexbox (Одномерные макеты)
| Элемент | Класс / Селектор | Реализация |
|---------|------------------|------------|
| **Навигационное меню** | `.main-nav ul` | `display: flex`, `justify-content: center`, `flex-wrap: wrap`. Обеспечивает горизонтальное расположение ссылок с автоматическим переносом на узких экранах. |
| **Карточки «Гаджеты недели»** | `.flex-cards-container` | `display: flex`, `flex-wrap: wrap`, `gap: 20px`. Карточки (4 шт.) выстраиваются в ряд с помощью `flex: 0 0 calc(25% - 15px)`. |

### 2. CSS Grid (Двумерные макеты)
| Элемент | Класс / Селектор | Реализация |
|---------|------------------|------------|
| **Дашборд «Сравнение характеристик»** | `.grid-dashboard` | `display: grid`, `grid-template-columns: repeat(3, 1fr)`, `gap: 20px`. 6 блоков характеристик автоматически выстраиваются в сетку **3 колонки × 2 строки**. |

### 3. Адаптивная вёрстка (Медиа-запросы)
Реализовано плавное перестроение макета без горизонтальной прокрутки (благодаря `box-sizing: border-box` и `width: 100%`):

| Разрешение экрана | Flex-карточки (Гаджеты) | Grid-дашборд (Характеристики) | Навигация |
|-------------------|-------------------------|-------------------------------|-----------|
| **Десктоп** (> 1024px) | **4** в ряд (`25%`) | **3** колонки (`repeat(3, 1fr)`) | Горизонтальная |
| **Планшет** (≤ 1024px) | **2** в ряд (`50%`) | **2** колонки (`repeat(2, 1fr)`) | Горизонтальная (с переносом) |
| **Мобильный** (≤ 768px) | **1** в ряд (`100%`) | **1** колонка (`1fr`) | Вертикальная (столбиком) |

### 4. Семантика и тег `<data>`
* **Семантические теги:** Для независимых карточек контента (гаджеты, блоки характеристик) использован тег `<article>`, что улучшает структуру документа и SEO. Для навигации использован `<nav>`.
* **Машинно-читаемые данные:** Числовые значения характеристик обёрнуты в тег `<data value="...">` (например, `<data value="3.2">3.2 ГГц</data>`). 
* **Стилизация `<data>`:** Через CSS (`font-size: 2.5rem`, `font-variant-numeric: tabular-nums`) цифры визуально выделены как ключевые метрики дашборда, сохраняя при этом машиночитаемость для скринридеров и парсеров.

### 5. Контрастность и доступность (WCAG)
* Фон карточек: `#1a1a1a` (тёмно-серый)
* Основной текст: `#e0e0e0` (светло-серый)
* Акцентный текст (цифры): `#c0c0c0` (серебристый)
* Коэффициент контрастности: **~12.6:1** для основного текста и **~10.3:1** для акцентного (требование: не менее 4.5:1) ✅

### 6. Наследие
* **Стиль «Металлик»:** Градиенты, тени и анимации `.metallic-card` применены к новым Flex и Grid элементам.
* **Позиционирование:** `relative` / `absolute` для бейджей.
* **Псевдоклассы:** Состояния `:hover`, `:active`, `:focus`, `:visited` работают для всех новых интерактивных элементов (ссылки меню, карточки).
* **Три способа подключения стилей:** Внешний, внутренний (для полей ввода) и inline (для заголовка) сохранены.
